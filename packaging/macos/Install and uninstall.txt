AudioLab — core tester app

INSTALL
Drag AudioLab.app to Applications. Eject this disk image, then open AudioLab
from Applications. No Terminal, Python installation or account is needed.

This personal tester build is not verified/notarized by Apple. If macOS blocks
it, first check that you downloaded it from JSummerer/AudioLab on GitHub.
If you choose to trust it, open System Settings > Privacy & Security, find the
blocked AudioLab entry, click Open Anyway, and follow macOS's confirmation.
Do not disable Gatekeeper or run commands that remove security protections.

The core app includes Save/Convert, Check and Light/Standard Enhance.

OPTIONAL AI
In a build with a compatible AI release catalog, open Settings > AI & system
and choose Enable AI features for Split and Best enhancement. This optional
download includes its own runtime and both model choices. Once installed,
local audio works offline. No Terminal, Python, Homebrew or uv setup is needed.
Settings shows known sizes, progress and errors. Allow extra disk space for
unpacking and audio work. Hardware and performance are not yet qualified.
Cancel install keeps a partial download; Resume continues it. Repair reinstalls
the compatible version. Update AI add-on follows the app's release catalog.
Remove AI add-on clears its owned runtime, models, cache and partial downloads
after confirmation; your recordings, Library and settings stay. Finish or
cancel AI jobs before updating or removing it. Shared/source packages stay.
Published 2.4.0b1 has no AI installer; this option is for the upcoming 2.4.0b2 beta.

UPDATE
Quit AudioLab and replace AudioLab.app with the newer copy from GitHub Releases.
Your recordings and Library remain separate from the application. Check
Settings for a compatible AI add-on update after replacing the main app.

UNINSTALL
Quit AudioLab and move AudioLab.app to the Trash.
To also remove AudioLab's settings, Library and kept original copies, first use
Settings > About > Open app data / Open logs. After quitting,
move the AudioLab folders shown there to the Trash if you no longer need them.
Keep any audio you want before removing app data. Your finished recordings
(normally Music/AudioLab) are your files and are not automatically removed.

macOS may retain its own WebKit caches, preferences and system records.
Detailed optional cleanup paths and troubleshooting:
https://github.com/JSummerer/AudioLab/blob/main/docs/MACOS.md
